**Generative blueprint studio and building-code compliance verification**

- Turns written design briefs into vector floor plans, editable in an interactive 2D canvas and a real-time 3D viewer
- Deterministic compliance engine: a pure-Python geometric rules engine checks drawings against code clauses with no LLM guesswork
- Citations recorded in a Neo4j knowledge graph; one-click handoff from design to audit
- Exports to IFC, DXF, PDF, SVG and GeoJSON

<img src="https://skillicons.dev/icons?i=py,fastapi,nextjs,neo4j,threejs&theme=dark" height="34" alt="Python, FastAPI, Next.js, Neo4j, Three.js"/>

**Spotify track analytics and recommendation**

- Python pipeline cleans the 30,000-song catalog, loads a PostgreSQL warehouse and exports compact JSON
- React + Vite dashboard for genre, popularity and audio-feature analytics
- Explainable content-based recommendations that run in the browser; deployed on Vercel
